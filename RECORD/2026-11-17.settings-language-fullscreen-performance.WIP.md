## The common part (all the engines with a settings screen)

- **engine-specs `^0.4.1` → `^0.6.0`**. The app imports the helpers from `../engine-specs.js`, the
  runtime copy the Makefile already ships beside the SDK.
- **English and Spanish**:
  - every string of the app (today Spanish, inline) moves into one `{ en, es }` table;
  - the table is read through `host.locale ?? resolveLocale()`;
  - SDK errors stay English and are shown as a detail under the app's own words.
- **Pause menu**: Continuar, the engine's entries, **Ajustes**, **Pantalla completa**, Volver al
  lanzador (UX.md rule 4).
- **Ajustes**: `createSettingsScreen()`.
  - Rows come from `settingsModel()` over the SDK's `config()` / `options()` descriptors (only those
    with a `label`), plus `SHARED_SETTINGS`.
  - A live change is applied at once.
  - A non-live one is saved and passed at the next start; its row says "Se aplica al reiniciar".
  - Choices are saved per engine with `saveSettings('jgenesis')` and read at mount with
    `loadSettings()`.
- **Fullscreen**: `createFullscreenToggle(root)` (Cmd+Enter / Alt+Enter, Select + Y), plus the
  pause-menu entry.
- **Performance**:
  - `createWakeLock()`, held while playing when "Mantener la pantalla encendida" is on (default
    on);
  - `createPerfCounter()` when "Mostrar rendimiento" is on: fed once per emulated frame where the
    SDK reports frames, else counting display frames.
- **Controls and audio pacing**: per engine, below.
- **Checks**:
  - `make test` / build;
  - in Chromium, with the owner's test ROMs where needed: the pause menu, every setting applied (or
    noted as on restart), saved across a reload, fullscreen by key and by menu, the counter, en / es;
  - a phone width.
- **Release**: minor.

## jgenesis

- **Settings**: the 26 options in `src/jgenesis.options.ts`, all live through `WebConfigRef`
  (filtering, blending shader, prescaling, aspect per system, region, sprite limits, low-pass…).
  - Per-system rows only when that system is running (`engineConfig.supports`).
  - They become `label` / `group` / `valueLabels` with Spanish added.
- **Controls**: partial.
  - jgenesis-web reads the keyboard only. The SDK turns the gamepad into key events through its
    table (`jgenesis.sdk.ts`: per system, button → `KeyboardEvent.code`).
  - Remapping the **gamepad** is changing that table: feasible.
  - Remapping the **keyboard** depends on jgenesis-web's own input config: to check. If it cannot be
    set from outside, keys stay fixed and the Controls rows show them read-only.
- **Audio pacing**: not offered. The emulator runs its own loop inside the WASM (WebGPU).
- **Order**: third.
